One-time setup. Your GitHub token is encrypted with the passcode you choose and stored only in this browser.

How do I get a token?
  1. Open GitHub → New fine-grained token.
  2. Name it e.g. Portfolio admin and pick an expiry date.
  3. Repository access: Only select repositories → Manuella-R.github.io.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy the token, and paste it above.
